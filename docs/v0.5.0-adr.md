# Angelus v0.5.0 — 架构决策记录（ADR）

> 状态：**已批准，待实现**（不构成发版；v0.5.0 标签待 roadmap 其余内容完成后另行决定）
> 本文件记录 v0.5.0 的两项关键决策：外部产品接入方式（Q1）与前端性能修复范围（Q2）。
> 契约与分阶段规格分别落盘 `docs/product-adapter.md` 与 `docs/v0.5.0-spec.md`。

---

## Q1 外部产品（claude code / codex）如何接入 angelus

**问题**：angelus 能否观察/驱动/控制 claude code 与 codex 的会话？

**结论**：**能，且做成插件 v2 扩展点 `register_external_product(adapter)`，不写进核心。**

- **观察（Phase 0）**：纯读文件即可。
  - claude code：`~/.claude/projects/<cwd-hash>/<session>.jsonl`（type ∈ {user, assistant, mode, permission-mode, file-history-snapshot, system, attachment, last-prompt}；assistant 行含 `message.content` 数组，含 text/tool_use/thinking）。
  - codex：`~/.codex/sessions/<date>/rollout-*.jsonl`（type ∈ {response_item, event_msg, session_meta, turn_context}；response_item.payload.type ∈ {function_call, function_call_output, message, reasoning}）。
- **驱动（Phase 1）**：
  - claude code：`claude -p --output-format=stream-json` + `--input-format=stream-json`，hooks（`PreToolUse`/`PostToolUse` 等）+ `--include-hook-events` 提供审批门。
  - codex：`codex exec` / `codex resume` / `codex queue` 可注入；**无原生审批门**，标注为限制。
- **上下文历史（Phase 2）**：把外部会话的归一化事件接入 angelus 图记忆/上下文历史。

**关键约束**：
1. 外部产品**不写进 angelus 核心**——核心只定义 `ProductAdapter` 契约（见 `docs/product-adapter.md`），具体产品适配器由插件提供。
2. 适配器契约与插件 `api_version` v2 绑定；v1 插件不受影响。
3. 数据边界：读取外部 transcript 属**只读**操作；驱动/控制必须显式声明权限（对应插件权限枚举扩展）。

## Q2 前端卡顿根因与修复范围

**问题**：前端在长会话（如 172MB / 8670+ 行 events.ndjson）下卡顿。

**结论**：11 个根因中，本期修复 **P0 三件套**：

| # | 根因 | 修复 | 代码位置 |
|---|------|------|----------|
| P0-1 | 后端 SSE 每 0.25s **全量重读** events.ndjson | 改为**按文件字节 offset 增量 tail**，只读新增行 | `angelus/storage.py::_read_session_event_log_from` + `angelus/api/runs.py::stream_events` |
| P0-2 | SSE 驱动刷新**无 debounce**，事件突发时高频全量重渲染 | 对 graph/plan 重载加 **150ms debounce** | `frontend/static/app.js::scheduleGraphPlanReload` |
| P0-3 | `agentStateView` 用 `traceEvents.find` 做 **O(n) 扫描** | 维护**每 Agent 最新事件 Map 索引**，O(1) 查询 | `frontend/static/app.js::traceEventIndex` |

**实测效果**（172MB 真实文件）：
- 全量读：2.195s；增量 tail（末 2KB）：0.0002s → **约 9256x**。
- 全量测试 340 passed（含 SSE 回归、前端资产断言、Spike 单测）。

**非本期**（其余 8 个根因，留后续）：chat-view 逐 token 滚动、renderJson 全展开、trace-view JSON.stringify 进 pre、dom.js escapeHtml 建 DOM、renderMemorySessionPicker、persistSettings、loadWorkspaces、loadUsage 等。
