## Phase 0 — 观察（Spike 已验证）

**目标**：把 claude/codex 的 transcript 归一化为统一 schema，写入 ledger，验证
ProductAdapter 契约在真实数据上成立。

**交付**：
- `scripts/spike_product_adapters/adapters.py`：ClaudeAdapter / CodexAdapter（`iter_events`）。
- `scripts/spike_product_adapters/run_spike.py`：扫描真实 transcript → 归一化 → 契约断言 → `out/ledger.ndjson`。
- `tests/test_spike_product_adapters.py`：3 个单测（claude 归一化、codex 工具往返、developer→meta）。

**验收**：
- [x] 两个产品至少各解析出 1 条 user 与 1 条 assistant 事件；
- [x] 所有事件字段类型符合 schema，`seq` 单调递增；
- [x] 畸形行跳过不抛异常；
- [x] 真实数据 94,273 条事件归一化通过。

**后续（Phase 0 生产化，不在本 Spike）**：
- ledger 落盘位置与 angelus `events.ndjson` 对齐（`storage._append_session_event` 或独立 ledger 目录）；
- 增量 tail 复用 `_read_session_event_log_from` 的字节 offset 语义。

## Phase 1 — 控制

**目标**：从「观察」推进到「驱动/控制」外部产品会话。

**范围**：
- claude code：`claude -p --output-format=stream-json --input-format=stream-json` 注入；
  hooks（`PreToolUse`/`PostToolUse`）+ `--include-hook-events` 提供审批门。
- codex：`codex exec` / `codex resume` / `codex queue` 注入；**无原生审批门**，标注为限制。

**验收**（待实现）：
- [ ] 适配器声明 `capabilities`（drive / control / stream）；
- [ ] 未声明能力不提供 UI 入口；
- [ ] 驱动操作经权限校验（`external_product:control`），未授权拒绝并记日志。

## Phase 2 — 上下文历史

**目标**：把外部会话的归一化事件接入 angelus 上下文历史 / 图记忆。

**范围**：
- 归一化事件 → 图记忆实体/关系（复用 `graph_context_design.md` 的图检索与持久化）；
- 外部会话可作为 angelus 会话的「上下文来源」参与压缩/归档。

**验收**（待实现）：
- [ ] 外部会话可被索引并检索；
- [ ] 上下文历史面板展示外部会话的归一化事件。

## 性能修复（本 PR 已实现）

**P0-1 后端 SSE 增量 tail**
- `angelus/storage.py`：新增 `_read_session_event_log_from(workspace_id, session_id, offset_bytes)`
  与 `_session_event_offset_after(workspace_id, session_id, after)`；
- `angelus/api/runs.py::stream_events`：`generate()` 与 `replay_historical()` 改用字节 offset 跟踪；
- 语义保持：`after` 仍为「已渲染记录数」，历史回放兼容；畸形行推进 offset 防死循环；尾部半行不消费、下轮重试。
- 实测：172MB 文件全量读 2.195s → 增量 tail 0.0002s（约 9256x）。

**P0-2 前端 SSE 驱动刷新 debounce**
- `frontend/static/app.js`：新增 `debounce(fn, 150)` 与 `scheduleGraphPlanReload`；
  graph/plan/task 事件、result、done 统一走 debounced 重载。

**P0-3 agentStateView 索引化**
- `frontend/static/app.js`：新增 `traceEventIndex`（Map<agentId, 最新事件>），
  `indexTraceEvent` / `rebuildTraceEventIndex` 维护；`agentStateView` 由
  `traceEvents.find`（O(n)）改为 `traceEventIndex.get`（O(1)）。

**验收（已通过）**：
- [x] `tests/test_sse_stream.py` 3 passed（after 语义、无 active 回放、compaction 事件可达）；
- [x] `tests/test_workbench_assets.py` 21 passed（含 done 处理器改用 debounced reload 的断言更新）；
- [x] 全量 `tests/` 340 passed；
- [x] `node --check frontend/static/app.js` 语法通过。
