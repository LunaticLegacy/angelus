如何使用 External Agent Hub
  1. 自动检测：检查本机 Codex、Claude Code 与本地 OpenCode 服务。卡片的“本机可用”仅代表可启动或可连接。
  2. 选择 Provider：Codex 与 Claude Code 不需要 URL；OpenCode 才需要保存 loopback 地址。
  3. 探测运行时：Codex 会启动 App Server 并完成握手；显示“已完成握手”后即可安全发现会话。
  4. 发现会话：仅读取 Provider 暴露的会话列表，不会向 Agent 发送消息或执行工具。
  5. 连接会话：当前浏览器标签会申请控制 lease；未取得 lease 时仅能观察。
  6. 执行控制：取得 lease 后，只有 Provider 宣称支持的固定操作才会显示。Claude 已有的外部会话通常为只读。
若 Codex 探测失败，请确认本机的 codex app-server 可正常启动并已完成登录。
